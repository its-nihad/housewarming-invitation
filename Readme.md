# Housewarming Invitation

A premium housewarming invitation card for Mohammed and Fathima, built as a single HTML file with plain HTML, CSS and JavaScript. It uses a deep emerald and gold theme with an arched ivory card, soft drifting gold light and a gentle fade-in on load. There are no external libraries or assets, so it works offline and loads instantly on any phone.

Click this link to view the project: https://its-nihad.github.io/housewarming-invitation/

The invitation is hosted on GitHub Pages straight from index.html in this repository, so any change you commit will go live at the same link after a minute or two.

To personalise it, open index.html and find the EVENT block at the bottom of the script. Change the date, time and place there, and the page will update the date display, the location button and the calendar button automatically. The host names and venue text are in the HTML near the top of the card, and the colours are defined as variables at the start of the stylesheet.
